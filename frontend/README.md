# Interfaz de Foro Académico

La interfaz utiliza Angular 21 y la cuadrícula de Bootstrap. Los componentes de cuenta, portada, editor, detalle y moderación consumen las colecciones de `EstadoForo`. Los cambios persisten en el navegador y cada pestaña conserva su propia sesión.

Para compilar desde esta carpeta:

```shell
npm ci
npm run build
```

La ejecución general con Docker y la verificación de las API se describen en el [README del proyecto](../README.md).
